Starhold 生产环境已就绪
1. 配置 kubectl

aws configure    # region 填 us-east-1
aws eks update-kubeconfig --name starhold-prod-eks --region us-east-1
kubectl get nodes    # 看到 2 台节点 = 通

2. 镜像仓库（你们自己建） 你们的 IAM 权限已包含 ecr:CreateRepository，每个服务自建一个：

aws ecr create-repository --repository-name starhold/<service> \
  --image-scanning-configuration scanOnPush=true --region us-east-1

建议命名 starhold/api、starhold/web、starhold/worker 这种。完整地址：

746669197317.dkr.ecr.us-east-1.amazonaws.com/starhold/<service>:<tag>

推镜像登录：

aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin 746669197317.dkr.ecr.us-east-1.amazonaws.com

3. 数据库（不需要密码，直接读 K8s Secret）

PostgreSQL 16，端点已限内网，仅集群内 Pod 可达
Secret：default/starhold-db，字段：host / port / username / password / database
Pod 里这样用：

env:
  - { name: PGHOST,     valueFrom: { secretKeyRef: { name: starhold-db, key: host     }}}
  - { name: PGPORT,     valueFrom: { secretKeyRef: { name: starhold-db, key: port     }}}
  - { name: PGUSER,     valueFrom: { secretKeyRef: { name: starhold-db, key: username }}}
  - { name: PGPASSWORD, valueFrom: { secretKeyRef: { name: starhold-db, key: password }}}
  - { name: PGDATABASE, valueFrom: { secretKeyRef: { name: starhold-db, key: database }}}

跨 namespace 用：让运维把 Secret 复制一份过去。

4. 存储（直接申请 PVC 即可，默认 gp3）

apiVersion: v1
kind: PersistentVolumeClaim
metadata: { name: data }
spec:
  accessModes: [ReadWriteOnce]
  resources: { requests: { storage: 20Gi } }

5. 公网 HTTPS 入口
ALB Controller 已部署，写 Ingress 自动出公网 ALB
通配符证书 *.starhold.uk 已签发；想用新子域名（比如 api.starhold.uk / admin.starhold.uk），写 Ingress 时把 host 设好，部署后告诉运维 ALB 的 DNS 名，他来加 Cloudflare CNAME
证书 ARN 找运维要（或用 aws acm list-certificates 自己查）
Ingress 模板：
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: api-ingress
  annotations:
    alb.ingress.kubernetes.io/scheme: internet-facing
    alb.ingress.kubernetes.io/target-type: ip
    alb.ingress.kubernetes.io/listen-ports: '[{"HTTPS":443}]'
    alb.ingress.kubernetes.io/ssl-redirect: "443"
    alb.ingress.kubernetes.io/certificate-arn: "<向运维要>"
spec:
  ingressClassName: alb
  rules:
    - host: api.starhold.uk
      http:
        paths:
          - { path: /, pathType: Prefix, backend: { service: { name: <你的Service>, port: { number: 80 }}}}
部署后：

kubectl get ingress -A    # 拿 ADDRESS 列的 ALB DNS 名 -> 发我加 CNAME

6. 注意
不要修改 kube-system 命名空间下的资源（平台组件）
不要碰 RDS 控制台关删除保护、关备份
数据库密码不要明文写代码，永远从 Secret/starhold-db 读
